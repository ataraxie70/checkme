# CI and release gate

CheckMe! uses the following integration gate before code can enter `main`:

```text
Pull Request
    |
    v
Foundation checks
    |
    +-- npm ci --dry-run
    +-- npm ci
    +-- architecture:test
    +-- lint
    +-- typecheck
    +-- test
    +-- build
    |
    v
Review + approval
    |
    v
main
```

## Reproducibility requirement

`package-lock.json` is authoritative for CI installation. It must be generated by npm and committed together with dependency changes.

Do not hand-edit dependency resolution data.

## Local verification

Before opening a pull request:

```bash
npm ci
npm run lockfile:check
make check
```

If `npm ci` or the lockfile check fails, dependency state is not considered reproducible and the change must not be merged.
